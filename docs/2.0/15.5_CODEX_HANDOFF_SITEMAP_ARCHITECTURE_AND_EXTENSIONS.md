Objective:
Codex should make the sitemap system accurate, scalable, and aligned with Google's sitemap guidance.

Codex should:

1. verify whether the site actually needs a sitemap improvement pass
2. fix or improve sitemap generation where the repo controls it
3. make sure the sitemap reflects canonical index targets
4. add sitemap indexes or extensions only when justified
5. leave clear implementation summary and human TODO outputs

Why:

- sitemap architecture
- sitemap generation quality
- sitemap indexing strategy
- sitemap extensions for images, video, news, and localized URLs
- sitemap submission and validation workflow
