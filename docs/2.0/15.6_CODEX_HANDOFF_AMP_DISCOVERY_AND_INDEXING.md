Required suite controls:
- Read `docs/2.0/V2_SUITE_SHARED_EXECUTION_CONTRACT.md` and the current `docs/v2-generated-docs/V2_SUITE_RUN_LEDGER.md` before executing this handoff.
- Give the user the required pre-execution rundown before the first write or implementation action.
- Create or refresh this handoff's detailed report, implementation summary, and human or owner TODO; use the ledger-assigned fallback path when an older output list omits one member of the trio.
- Update this handoff's ledger row and append history when work begins and ends.

Objective:
Codex should make AMP pages easier for Google to discover, validate, index, and serve correctly in Google Search without breaking the canonical non-AMP experience.

Codex should:

1. verify whether AMP exists in the repo
2. verify whether AMP is canonical AMP or paired with canonical non-AMP pages
3. fix AMP discovery and canonical relationship issues
4. fix AMP validation, structured-data, and robots issues that the repo can safely fix
5. leave implementation summary and human TODO outputs

Why:
Use this handoff only when the repo actually has AMP pages, AMP variants, AMP templates, or an AMP publishing path.

Use this after:

- `15_CODEX_HANDOFF_INDEXING_AND_CRAWL_READINESS.md`

Optionally use it after:

- `15.5_CODEX_HANDOFF_SITEMAP_ARCHITECTURE_AND_EXTENSIONS.md`

This handoff is intentionally separate from the main indexing handoff because many repos do not use AMP at all.

If the repo has no AMP implementation, Codex should say so briefly and stop rather than invent AMP work.
