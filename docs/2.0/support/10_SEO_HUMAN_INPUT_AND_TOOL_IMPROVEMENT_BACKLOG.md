# SEO Human Input And Tool Improvement Backlog 2.0

Objective:
Track items Codex should not guess: business approvals, external account checks, live platform verification, and tooling improvements.

Use this when:

- a handoff needs Search Console, Analytics, Google Business Profile, Resend, Stripe, Calendar, or Cloudflare confirmation
- a recommendation depends on business facts not present in the repo
- a repeatable script or report generator would reduce future manual work

Human-input examples:

- approve public claims, pricing, service-area coverage, credentials, and guarantees
- validate Search Console fixes after deployment
- confirm Analytics/GTM events and conversion definitions
- confirm Google Calendar and Resend notification behavior from live submissions
- approve backlink/outreach targets and citation opportunities

Tooling backlog examples:

- route inventory generator
- env inventory generator
- page-content keyword directory generator
- Search Console export summarizer
- Analytics export summarizer
- generated-doc path validator for `docs/v2-generated-docs/`

Generated output:

- Put backlog and owner TODO files in `docs/v2-generated-docs/` for main v2 work.
- Put support-specific TODOs in `docs/v2-generated-docs/support/`.
