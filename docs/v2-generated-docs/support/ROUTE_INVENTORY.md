# Route Inventory

## Routing Baseline

The application uses the Next.js 16 App Router. Route entrypoints and server-owned metadata live under `src/app/`; reusable client page compositions live under `src/screens/`. Internal navigation uses `next/link`, and `RouteEffects` only retains browser scroll/hash behavior.

OpenNext packages the application into `.open-next/worker.js` and `.open-next/assets` for a Node.js-compatible Cloudflare Worker mapped to `utahonecall.com`.

## Public Routes

| Path | Route file | Runtime page | Content state | Indexability |
|---|---|---|---|---|
| `/` | `src/app/page.tsx` | `HomePage` | Full home page | Indexable; canonical metadata |
| `/services` | `src/app/services/page.tsx` | `ServicesPage` | Full services page with anchors | Indexable; canonical metadata |
| `/about` | `src/app/about/page.tsx` | `AboutPage` | Full company/about page | Indexable; canonical metadata |
| `/about/social-media` | `src/app/about/social-media/page.tsx` | `PlaceholderPage` | Placeholder | Indexing decision unresolved |
| `/location` | `src/app/location/page.tsx` | `PlaceholderPage` | Placeholder | Indexing decision unresolved |
| `/emergency` | `src/app/emergency/page.tsx` | `PlaceholderPage` | Placeholder | Indexing decision unresolved |
| `/contact` | `src/app/contact/page.tsx` | `ContactPage` | Contact page and Formspree form | Indexable; canonical metadata |
| `/404` | `src/app/404/page.tsx` | `NotFoundPage` | Branded not-found page | Explicit `noindex, nofollow` |
| Any unmatched pathname | `src/app/not-found.tsx` | `NotFoundPage` | Framework not-found response | HTTP 404 and `noindex` through Next.js |

Route constants are owned by `src/config/site.ts`. Shared metadata is generated by `src/lib/metadata.ts` against `https://utahonecall.com`.

## Dynamic And Operational Routes

There are no dynamic route families, application-owned API routes, authenticated routes, redirects, or migration routes. Query strings do not select pages. Hash fragments remain client-side anchors, and `RouteEffects` scrolls to a matching target after navigation.
